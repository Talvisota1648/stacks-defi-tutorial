# Проверка MVP 2.0 в среде разработки

Проверки относятся к тестовым данным, не к работающей городской системе.

- 17 backend-тестов: доступы, атомарный лимит десяти источников, повторная загрузка,
  обязательная проверка, порядок approval-cursor, целостность материалов,
  эксклюзивные/восстанавливаемые аренды, накопление длительности, подавление повторов,
  сохранение контекста при очистке и частично записанный CSV сборщика.
- Один тест включает реальные ONNX-инференсы на CPU для десяти зарегистрированных
  источников с подготовленными видеофайлами. Проверены десять кандидатов, кадры,
  SHA-256, отсутствие выгрузки до решения и наличие после утверждения.
- Реальный RTSP от собственного MediaMTX и FFmpeg с тестовым изображением:
  поток → сегменты → очередь → CPU-инференс → карточка. Это один живой тестовый поток,
  а не испытание десяти внешних камер одновременно.
- Браузер с настоящими backend/worker/моделью: вход, создание upload-источника,
  загрузка клипа без зоны, первый кадр, рисование зоны, повторная обработка файла,
  кадр и видео события, обязательный комментарий, утверждение и интеграционная лента.
  Мобильная ширина 390 px проверена без горизонтального переполнения.
- Docker Compose на CPU: собраны образы, PostgreSQL запущен, модель скачана с проверкой SHA-256,
  проверены загрузка, реальный инференс, материалы, утверждение, интеграция и production web/API proxy.
  Отдельно проверен RTSP внутри контейнеров и сохранение предшествующего клипа при пороге 8 секунд.
  Для облачного HTTPS-прокси применялся локальный build-secret доверенного CA и сетевой override вне Git;
  проверка TLS и контрольные суммы не отключались.
- Переподключение RTSP проверено остановкой собственного издателя: ошибка зафиксирована,
  после возобновления поток снова начал давать обработанные клипы.
- Старые тесты ручного анализа сохраняются. Обязательные внешние платные вызовы
  в автоматическом контуре не выполняются.

Подготовленный файл теста — повторяющиеся кадры публичного примера `bus.jpg`:
https://github.com/ultralytics/ultralytics/blob/main/ultralytics/assets/bus.jpg
Он применяется только как воспроизводимая проверка детектора/правил; не коммитится
как городской материал и не доказывает точность на реальной сцене.

Границы проверки: нет доступной NVIDIA GPU, реальных городских камер и адреса
внешнего ситуационного центра. GPU-режим, точность классификации на территории
заказчика, десять параллельных внешних RTSP и фактическая интеграция с центром
нуждаются в отдельных испытаниях. Доля ложных срабатываний и полнота не измерены:
для этого нужен размеченный набор заказчика.
