# ОСЦ: MVP видеоанализа

Страница `/`: выбор или перетаскивание MP4/MOV/WebM до 250 МБ, предпросмотр,
категории поиска, место съёмки, анализ и экспорт JSON.
Оригинальное видео остаётся в браузере. Для анализа браузер извлекает 12
равномерно распределённых JPEG-кадров шириной до 1280 px. Кадры через сервер
отправляются в OpenRouter; файлы и результаты на сервере не сохраняются.
Короткие события могут попасть между кадрами и быть пропущены.

## Подключение

Задайте на сервере `OPENROUTER_API_KEY` и при необходимости `OPENROUTER_MODEL`
(по умолчанию `openai/gpt-4o-mini`). Требуются баланс OpenRouter и доступ модели
к изображениям и JSON-ответам. Ключ не используется в браузере.
В облачной среде разрешите `openrouter.ai` и запустите Node 24 с
`NODE_USE_ENV_PROXY=1`, чтобы использовать HTTPS-прокси платформы.
Для локальной разработки используйте игнорируемый `.env.local`.
Не размещайте ключ в `NEXT_PUBLIC_*`.

```sh
cd /workspace/stacks-defi-tutorial/frontend
NODE_USE_ENV_PROXY=1 NEXT_TELEMETRY_DISABLED=1 npm run dev -- --hostname 127.0.0.1 --port 3000
```

`GET /api/analyze` возвращает статус настройки без раскрытия ключа.
`POST /api/analyze` принимает 12 JPEG-кадров с временными отметками, длительность,
категории и место. Без ключа возвращается 503, ошибки провайдера — 502,
некорректный запрос — 400. Ответ модели проверяется по структуре и отметкам кадров.

## Ограничения

Это первичная проверка визуальных признаков. Геолокация вводится вручную;
юридический статус строений и действий не определяется. Номера могут оказаться
нечитаемыми. Видео должно декодироваться браузером; рекомендуется MP4/H.264.
В MVP нет учётных записей, хранения истории, очередей или ограничения расходов:
перед публичным размещением API нужны авторизация и квоты.

## Проверка

```sh
./node_modules/.bin/tsc --noEmit --incremental false
NEXT_TELEMETRY_DISABLED=1 npm run build
```

Проверить видео, извлечение 12 кадров, переход к отметке результата и экспорт.
Реальный вызов OpenRouter требует настроенного ключа; проверки с подменённым
ответом подтверждают интерфейс и обработку, но не качество модели.
