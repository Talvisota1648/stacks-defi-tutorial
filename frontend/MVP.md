# ОСЦ: анализ видео, фото и российских номеров

Страница `/` принимает видео MP4/MOV/WebM до 250 МБ и фото JPG/PNG/WebP до 20 МБ
(до 40 мегапикселей). Есть предпросмотр, категории, место съёмки и экспорт JSON.
Оригиналы остаются в браузере; сервер передаёт только подготовленные изображения
в OpenRouter и не хранит файлы или историю.

## Подключение и запуск

Нужны Node.js 24 с npm, интернет и серверный `OPENROUTER_API_KEY` с балансом.
`OPENROUTER_MODEL` по умолчанию `openai/gpt-4o-mini`.
Для локального запуска задайте ключ в игнорируемом `.env.local`, затем:

```sh
npm ci
npm run dev
```

Ключ нельзя помещать в `NEXT_PUBLIC_*` или коммитить. В облачной среде разрешите
`openrouter.ai` и запускайте Node 24 с `NODE_USE_ENV_PROXY=1` для HTTPS-прокси.
FFmpeg, Python, GPU и база данных для запуска приложения не нужны.

## Чтение номера

1. Откройте подходящий момент видео или фото.
2. Нажмите «Выделить область номера», обведите табличку с небольшим запасом,
   затем нажмите «Готово». Поддерживается мышь и сенсорный экран.
3. В видео рамка неподвижна: она должна покрывать номер одного и того же
   автомобиля на выбранных моментах. Автоматического детектора и трекера нет.
4. Браузер локально оценивает резкость 24 кандидатов в шести временных интервалах
   и выбирает по одному кадру из каждого. Это эвристика резкости выбранной
   области, а не проверка наличия номерного знака.
5. Один запрос содержит шесть общих кадров и шесть вырезок. Вырезки сохраняют
   исходное разрешение выбранной области; не растягиваются и не дорисовываются.
   Общие изображения уменьшены по длинной стороне до 1280 px. Если область
   слишком велика для лимита JPEG, приложение просит выделить её точнее.
6. Каждая вырезка получает своё прочтение, включая состояние «нечитаемо».
   Пропущенное прочтение не наследует номер другого кадра. Противоречия не
   разрешаются голосованием; требуется проверка пользователем.

Для фото отправляется общий снимок и, если выделена область, одна вырезка.
Без выделения отправляются 12 общих кадров видео или один снимок; номера
читаются на общей сцене и могут оказаться слишком мелкими.

Поддерживается стандартный российский автомобильный номер А123ВС77/А123ВС777.
Латинские двойники букв преобразуются в кириллицу, но цифры не заменяются
буквами и регион не угадывается. Специальные, мотоциклетные и другие форматы
пока не поддерживаются. Варианты видны отдельно от признаков нарушения.
«Совпадение» означает одинаковые читаемые ответы на разных изображениях,
а не подтверждение точности. Все прочтения получены одной моделью в одном
контексте: ошибки могут коррелировать. Сверяйте вырезки с символами.

Отдельных запросов на каждую вырезку нет; максимум 12 изображений на видео.
Это не гарантирует прежнюю стоимость: цена определяется токенами изображений
и ответа. Локальный выбор кадров не расходует баланс OpenRouter.

## Признаки нарушений

Номера находятся в отдельном разделе. Обычное движение, эвакуатор и перевозка
повреждённой машины сами по себе не считаются нарушением. Сервер требует
структурированные основания и ссылки на общие кадры, исключает обычную
деятельность и объединяет события с одинаковым eventId. Для эвакуатора нужны
отдельные наблюдаемые признаки нарушения, например сброс отходов.

ИИ может ошибаться: промпт и серверные фильтры снижают ложные срабатывания,
но не гарантируют их отсутствие. Правила участка, документы и юридический
статус по изображению не устанавливаются. Геолокация вводится вручную.
События между выбранными кадрами могут быть пропущены.

Отчёт JSON содержит подготовленные изображения с id/временем/размером,
индивидуальные прочтения, варианты и ссылки событий на изображения.

## API и проверка

`GET /api/analyze`: только статус наличия ключа. `POST`: `mediaType`,
`duration` (0 для фото), `location`, `categories`, `frames` (id, kind,
timestamp, image JPEG data URL, width, height). Без ключа — 503;
некорректный запрос — 400; сбой/невалидный ответ провайдера — 502.

```sh
npm test
./node_modules/.bin/tsc --noEmit --incremental false
NEXT_TELEMETRY_DISABLED=1 npm run build
```

Тесты включают конфликт номера, запрет переноса прочтения на другой кадр,
отсев обычной перевозки и один вызов провайдера. Подмена ответа в тестах
не проверяет качество модели; нужна дополнительная проверка на реальных файлах.
Перед публичным размещением нужны авторизация и ограничения расходов:
в текущем MVP их нет.
